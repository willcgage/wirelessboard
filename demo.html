Quick Start
  • Menu -> Config Edit slots, discovery, and logging settings.
  • Menu -> Planning Center Authorize PCO and sync assignments.
  • Menu -> Help Return to this guide any time.
Keyboard Shortcuts
  • ? Toggle this menu.
  • 1-9 Jump to saved groups (0 returns to the combined view).
  • F Enter or exit fullscreen.
  • G / V Cycle image or video backgrounds.
  • I Toggle the info drawer.
  • N Toggle slot editing (press Shift+N to show the paste box).
  • E Edit the current group (when viewing groups 1-9).
  • S Open the Config view.
  • Q Show the scannable URL.
  • Esc Return to the main board.
Need More Help?

Check the in-repo docs/ directory for deployment, discovery, and automation guides, or open an issue from the project home.

Keep another tab on the Config view during events so adjustments never interrupt the board.

Background Filenames

                

                  Wirelessboard looks for media named after the person assigned to each slot — the name shown on the board, lowercased and trimmed. A slot with nobody assigned falls back to the name its transmitter reports. Reference the expected filenames below when preparing artwork or videos.

5 · How positions match slots

            

              

                
                
                

                  Planning Center positions carry the mic name and number — a person under position
                  “Vocal 1” fills the slots labelled for mic 1 and IEM 1.
                

              

              

                

                  
                  
                  

                    Single-team plans only. Keys on the trailing number alone, so
                    with several teams scheduled “Vocal 1”,
                    “Guitar 1” and “Host 1” all claim the
                    same slot.
